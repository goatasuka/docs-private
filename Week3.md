## Revised Guide
Platform: Desktop browser, English interface
Audience: A first-time GitHub user who is already signed in.
Task: Create a private repository with a README.

Prerequisites
- A GitHub account with permission to create repositories
- A desktop browser signed in to GitHub.com

Steps
1. Click the plus “+” menu in the upper right corner of GitHub’s homepage and select New repository.
2. Enter the repository name `docs-practice` in the name field under your account.
3. Select Private to set the repository visibility.
4. Check the box for Add a README file.
5. Review your settings and click Create repository.

Result Check
The repository homepage loads automatically. Confirm the README content appears on the main page.
If GitHub returns an error saying the name is unavailable, return to Step 2 and choose another name.

Later use
This repository can store and organize your project documentation.

## Six Style Rules (Before / After)
Rule 1: Use imperative verbs for procedural instructions.
Before: You can open the + menu.
After: Open the + menu.

Rule 2: Keep one action per step. Avoid combining two operations in one sentence.
Before: Open the + menu and select New repository to start.
After: Open the + menu and select New repository.

Rule 3: Use consistent bold formatting for UI buttons and options.
Before: choose private
After: select **Private**

Rule 4: Avoid vague casual words; use precise technical terms.
Before: pick a name
After: Enter the repository name

Rule 5: Separate prerequisites into bullet points for scannability.
Before: You need an account and a browser.
After:
- A GitHub account with permission to create repositories
- A desktop browser signed in to GitHub.com

Rule 6: Add a clear result check so users know when they succeed.
Before: Then you are done.
After: The repository homepage loads automatically. Confirm the README content appears on the main page.
