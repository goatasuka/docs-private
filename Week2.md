# Quick Start Guide: Creating a Private Repository on GitHub.com

**Platform:** Desktop browser, English interface
**Audience:** A first-time GitHub user who is already signed in.
**Task:** Create a private repository with a README file.

## Prerequisites
- A GitHub account with permission to create repositories.
- A desktop browser signed in to GitHub.com.

## Steps
1. Open the **+** menu at the top-right corner of GitHub.com and select **New repository**.
2. Enter the name `docs-practice` in the repository name field under your own account.
3. Choose **Private** as the repository visibility.
4. Check the box to **Add a README file**.
5. Click **Create repository** to finish.

## Result Check
The new repository page loads automatically and displays the README file on the main page.
If GitHub says the name is already taken, choose another name (for example, `docs-practice-2026`) and try again.
